المحتويات:
- تطبيق أندرويد أصلي بلغة Java.
- يعرض موعد الدورة القادمة بشكل بارز مع اسم اليوم والتاريخ والساعة.
- تاريخ البداية الافتراضي: 17/11/2026 الساعة 03:30.
- مدة الدورة الافتراضية: 3 أيام و6 ساعات و30 دقيقة.

- حفظ الإعدادات محلياً والعمل دون إنترنت.

طريقة إنشاء APK:
1. افتح مجلد MaaAlManbaa بواسطة Android Studio على حاسوب.
2. انتظر مزامنة Gradle وتنزيل أدوات Android المطلوبة.
3. من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
4. اسمح للتطبيق بالإشعارات، واسمح بالمنبهات الدقيقة من إعدادات أندرويد إذا طلب ذلك.

ملاحظة: هذا مجلد مصدر Android Studio وليس ملف APK جاهزاً. يلزم Android SDK وAndroid Gradle Plugin لبناء APK.
